## ¿Qué hace esta app?

Olivos Verdes es una aplicación de frutería en línea donde los clientes pueden navegar productos, armar un carrito y hacer pedidos. También incluye un panel para que los administradores gestionen el catálogo y las órdenes.

### Para clientes

- **Catálogo** — Explora frutas por categoría, productos destacados y ofertas.
- **Carrito** — Agrega productos con cantidad, ve el total y genera pedidos.
- **Órdenes** — Consulta el historial y el estado de cada pedido.
- **Autenticación** — Registro, inicio de sesión, recuperación de contraseña y modo invitado.
- **Perfil** — Edita tus datos personales.

### Para administradores

- **Productos** — CRUD completo de frutas con imágenes.
- **Categorías** — CRUD de categorías.
- **Ofertas** — CRUD de ofertas con descuento.
- **Pedidos** — Visualiza y actualiza el estado de cada orden.

## Stack técnico

| | |
|---|---|
| **Framework** | Flutter + Material Design |
| **Backend** | Firebase Auth, Firestore, Storage |
| **Estado** | Provider |
| **Routing** | GoRouter |
| **Imágenes** | cached_network_image, image_picker |

## Primeros pasos

```bash
flutter pub get
flutter run
flutter analyze
```

> Requiere un proyecto Firebase con `google-services.json` (Android) y `GoogleService-Info.plist` (iOS). ID del proyecto: `olivosverdes-34cf7`.
